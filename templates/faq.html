Preguntas frecuentes

Encuentra respuestas sobre el funcionamiento de proyectos, tareas, participantes y permisos.

¿Qué puedo hacer dentro de un proyecto?

Puedes consultar la información del proyecto, gestionar tareas y participar en el equipo según el rol que tengas asignado.

¿Qué diferencia hay entre los roles?

El Encargado principal administra el proyecto y sus participantes. El Ayudante puede colaborar en la gestión del proyecto. El Colaborador puede trabajar sobre las tareas que tenga disponibles.

¿Cómo se calcula el progreso de un proyecto?

El progreso se calcula considerando el estado y la importancia de cada tarea. Las tareas con mayor importancia tienen un mayor peso en el progreso total.

¿Qué significan las estrellas de prioridad?

Las estrellas representan la prioridad del proyecto, utilizando una escala de 1 a 5. Esta prioridad es independiente de la urgencia de las tareas y no modifica el cálculo del progreso.

¿Qué ocurre cuando una tarea se acerca a su fecha límite?

Las tareas muestran una señal visual de urgencia según el tiempo restante para su fecha límite. Esta señal es independiente de la prioridad del proyecto.

¿Se pueden eliminar definitivamente los proyectos o tareas?

La aplicación utiliza eliminación lógica. Esto permite conservar la información necesaria para mantener el historial y la trazabilidad del sistema.

¿Quién puede crear tareas?

El Encargado principal y el Ayudante pueden crear tareas. Los Colaboradores pueden editar las tareas que tengan disponibles, pero no pueden crearlas ni eliminarlas.

¿Quién puede eliminar una tarea?

Solamente el Encargado principal puede eliminar tareas.

¿Qué enfoque se utiliza para las vistas?

El proyecto utiliza el enfoque FBV (Function-Based Views). Las vistas se implementan mediante funciones de Python que reciben una solicitud HTTP y gestionan el flujo correspondiente antes de devolver una respuesta.
La decisión de utilizar FBV no se debe a que el proyecto sea considerado más sencillo ni a que CBV sea técnicamente más complejo.
La decisión responde al orden de aprendizaje del curso:
* Este proyecto corresponde a la práctica de FBV.
* El siguiente proyecto será desarrollado utilizando CBV.
De esta manera se busca practicar explícitamente ambos enfoques en proyectos diferentes y respetar el orden en que fueron enseñados durante el curso.
